
### 📝 **Formatting**
- Italic: `Ctrl + I`
- Bold: `Ctrl + B`
- Highlight: `Ctrl + Shift + H`
- Strikethrough: `Ctrl + Shift + S`
- `Code Block`: `Ctrl + Alt + C`    
- **Bullet list**: `Ctrl + Shift + K`
- **Numbered list**: `Ctrl + Shift + L`-
- Regex : `Alt + H-
### 📚 **Folding & Headings**
- **Fold all headings and lists**: `Ctrl + Shift + X`
- **Unfold all headings and lists**: `Ctrl + Shift + C`
- **Toggle fold on the current line**: `Ctrl + Shift + V`zl
### 👁️‍🗨️ **Focus & Zen Mode**
- **Focus on current line (Enable Typewriter Mode)**: `Ctrl + Shift + D`
- **Disable Focus (Disable Typewriter Mode)**: `Ctrl + Shift + E`
- **Zen Mode Toggle**: `Ctrl + Shift + Z`
### 🗂️ **Daily Notes**
- **Open previous daily note**: `Ctrl + Alt + Y`
- **Open today's daily note**: `Ctrl + Alt + D`
### ⚙️ **UI / Navigation**
- **Settings**: `Ctrl + ;`
- **Open homepage**: `Ctrl + Alt + H`
- **Theme Picker**: `Ctrl + Alt + T`
- **Show Tags** : `Alt + F2
